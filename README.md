# IELTS Academic ฟรี · ห้องอ่าน

เว็บไฟล์เดียว (HTML + CSS + JavaScript) สำหรับฝึกอ่าน IELTS Academic ฟรี ไม่ต้องมีเซิร์ฟเวอร์

## มีอะไรบ้าง (เฟส 1)

- **คู่มือ:** ภาพรวมข้อสอบอ่าน ลำดับทำ 20 นาทีต่อบท เทคนิค T/F/NG เติมคำ จับคู่ย่อหน้า และ paraphrase
- **บทเรียน:** บทเรียนพื้นฐานพร้อมกฎ เทคนิคจำ สถานการณ์ใช้จริง และแบบฝึกท้ายบท (Tenses, Parts of Speech, กริยา 3 ช่อง, IPA, Connectives, If-clause) มีปุ่มฟังเสียงและบันทึกความคืบหน้าในเครื่อง
- **ห้องซ้อม:** บทอ่านต้นฉบับ 3 บท บทละ 10 ข้อ ครอบคลุม T/F/NG, Yes/No/NG, เติมคำ, จับคู่ย่อหน้า, จับคู่หัวข้อ และเลือกตอบ พร้อมตัวจับเวลาและเฉลยอธิบายเหตุผลทุกข้อ
- **สมุดผิดพลาด:** จดข้อที่พลาดพร้อมสาเหตุ สรุปว่าพลาดเรื่องอะไรบ่อย ส่งออก/นำเข้าเป็นไฟล์ JSON ได้

## ข้อมูลของผู้ใช้

- **ไม่ล็อกอิน:** เก็บใน localStorage ของเบราว์เซอร์เท่านั้น ไม่ส่งไปที่ใด
- **ล็อกอินด้วย Google (ไม่บังคับ):** สมุดผิดพลาดซิงก์ไปที่ Firestore ของโปรเจกต์ Firebase ของคุณ เก็บเป็นเอกสารเดียว `users/{uid}` ไม่เก็บอีเมลหรือชื่อ ข้อมูลในเครื่องกับบนคลาวด์จะถูกรวมกันโดยไม่ทับกัน

## ตั้งค่า Firebase (ประมาณ 10 นาที)

1. เข้า [console.firebase.google.com](https://console.firebase.google.com) → Add project (ปิด Google Analytics ได้)
2. Project settings → Your apps → เลือกไอคอนเว็บ `</>` → Register app → คัดลอกอ็อบเจ็กต์ `firebaseConfig`
3. Build → Authentication → Get started → Sign-in method → **Google** → Enable → เลือกอีเมลสนับสนุน → Save
4. Authentication → Settings → **Authorized domains** → Add domain `ชื่อผู้ใช้.github.io`
5. Build → Firestore Database → Create database → เลือก **Production mode** → เลือกโลเคชันที่ใกล้ (เช่น `asia-southeast1`)
6. แท็บ **Rules** → ลบของเดิม วางเนื้อหาจากไฟล์ `firestore.rules` → **Publish**
7. เปิด `index.html` แก้บรรทัด `window.FIREBASE_CONFIG={...}` ใส่ค่าจากข้อ 2 แล้ว commit
8. ทดสอบ: เปิดเว็บ → กด "ล็อกอินด้วย Google" → ทำแบบฝึกแล้วบันทึกข้อผิดพลาด → ดูใน Firestore → Data ว่ามี `users/<uid>` ขึ้นมา

ค่า `firebaseConfig` ไม่ใช่ความลับ ใครเปิดดูโค้ดก็เห็นได้ สิ่งที่ปกป้องข้อมูลจริงคือกฎใน `firestore.rules` ห้ามปล่อยฐานข้อมูลเป็น test mode

แผน Spark (ไม่ต้องใส่บัตร) พอสำหรับการใช้คนเดียว ตรวจโควตาล่าสุดที่หน้าราคาของ Firebase

## ปัญหาที่พบบ่อย

- **ล็อกอินไม่ผ่าน (unauthorized-domain):** ยังไม่ได้เพิ่มโดเมน GitHub Pages ในข้อ 4
- **ซิงก์ไม่ได้ (permission-denied):** ยังไม่ได้วางหรือกด Publish กฎในข้อ 6
- **เปิดจาก LINE/Facebook แล้วล็อกอินไม่ได้:** Google บล็อกเบราว์เซอร์ในแอป ให้เปิดลิงก์ใน Chrome หรือ Safari
- **ป๊อปอัปไม่ขึ้น:** อนุญาตป๊อปอัปสำหรับเว็บนี้


## เพิ่มบทฝึกใหม่

เพิ่มชุด `PAx` (ย่อหน้า) และ `Gx` (กลุ่มข้อสอบ) ในส่วน `<script>` ของ `index.html` แล้วเพิ่มรายการใน `PS` แต่ละข้อมีรูปแบบ `[เลขข้อ, โจทย์, เฉลย, คำอธิบาย]` (ข้อ mcq เพิ่มตัวเลือกเป็นสมาชิกที่ 5)

## เพิ่มบทเรียนใหม่

ใน `<script>` ส่วนบทเรียนของ `index.html` เพิ่ม `LS.ชื่อ={ic,t,sub,s:[[หัวข้อ,HTML],...],q:[[โจทย์,[ตัวเลือก],เลขเฉลย(เริ่ม 0),คำอธิบาย]]}` แล้วเพิ่มชื่อใน `GROUPS` ถ้ามีชื่ออยู่แล้วแบบปุ่มเทา ระบบจะเปิดให้ใช้เองเมื่อมีบทเรียนที่ชื่อ key ตรงกัน

## ข้อจำกัด

- บทอ่านเขียนขึ้นใหม่เพื่อการฝึก ชื่อสถานที่และตัวเลขเป็นข้อมูลสมมติ
- ไม่เกี่ยวข้องกับ British Council, IDP หรือ Cambridge University Press & Assessment
- รูปแบบข้อสอบอาจเปลี่ยน โปรดยืนยันที่เว็บทางการของ IELTS ก่อนสอบ
